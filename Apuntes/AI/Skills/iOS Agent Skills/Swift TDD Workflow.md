# Swift TDD Workflow

## **Propósito**

Guiar el desarrollo test-first mediante el ciclo rojo, verde y refactorización.

## 🎯 ¿Cuándo usarla?

Al implementar o corregir funcionalidades con TDD en Swift.

## 🔎 Qué cubre

- Escribir una prueba que falle, aplicar el cambio mínimo y refactorizar manteniendo las pruebas verdes.
- Usar Swift Testing para pruebas unitarias y de integración; la skill contempla XCTest como alternativa y XCUITest para flujos de UI críticos.
- Aplicar pruebas parametrizadas, nombres claros y #require para opcionales.
- Aislar dependencias con mocks adecuados y comprobar ViewModels en MainActor cuando corresponda.
- Medir cobertura sin confundirla con calidad y evitar pruebas frágiles o ligadas a implementación.

## 📄 Resultado

Pruebas ejecutables y cobertura según los objetivos del proyecto y de la skill.
