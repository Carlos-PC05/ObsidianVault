# Swift Coding Standards

## **Propósito**

Aplicar convenciones de Swift que priorizan claridad y mantenibilidad.

## 🎯 ¿Cuándo usarla?

Al escribir, refactorizar o revisar código Swift.

## 🔎 Qué cubre

- Usar nombres claros en el punto de uso y el nivel de acceso mínimo necesario.
- Preferir inmutabilidad, manejar errores explícitamente y evitar force unwraps injustificados.
- Aplicar async/await y ejecutar tareas independientes concurrentemente cuando tenga sentido.
- Mantener vistas y ViewModels comprensibles, evitando valores mágicos y código duplicado.
- Revisar comentarios, documentación y pruebas siguiendo las convenciones del proyecto.

## 📄 Resultado

Guía de convenciones y lista de comprobación de calidad.
