-  `robots.txt` - archivo que indica a los buscadores qué partes de la web no deben rastrear, ahorrando recursos.
- `sitemap.xml` - mapa que lista las URLs importantes de tu sitio para facilitar su descubrimiento e indexación
-  **Open Graph** - es un protocolo de metadatos que utiliza etiquetas HTML en el código de una web para controlar qué titulo, descripción e imagen se muestra al compartir un enlace en redes sociales o aplicaciones de mensajería.
- **Canonical** - es un código HTML que indica a Google cuál es la página principal u oficial cuando existen varias URLs con contenido igual o muy parecido.
- **SSG** - Static Site Generation, **SSR** - Server-Side Rendering
